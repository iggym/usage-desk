# Asset provenance

All runtime imagery is served from the repository. No CDN, external font, analytics image, generated-image API or remote logo request is made by the app.

| Asset                       | Provenance / purpose                                                                                                                                                                   |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assets/desk-hero.webp`     | Extracted unchanged from the existing homepage's inline WebP; retained original desk concept imagery.                                                                                  |
| `assets/focus.webp`         | Extracted unchanged from the existing homepage's inline WebP; retained prompt-library imagery.                                                                                         |
| `assets/agent-world.webp`   | AI-generated photorealistic editorial concept: a glass sphere, orbital connections and miniature workspaces. Optimized to WebP. Not a product screenshot or documentary image.         |
| `assets/compute-world.webp` | AI-generated photorealistic editorial concept: a cinematic data-center corridor. Optimized to WebP. Not a photograph of a named facility and not a visualization of measured capacity. |
| `assets/favicon.svg`        | Original local usage-bars mark used by this interface.                                                                                                                                 |
| Inline UI icons             | Locally authored SVG line icons; decorative icons are hidden from assistive technology and accompanied by text.                                                                        |
| Dot orb                     | CSS-rendered illustrative motif, not an official logo. The product is identified in accompanying text.                                                                                 |

The existing repository's MIT [license](../LICENSE) is retained. No new provenance claim is made for the inherited images beyond their presence in the original repository.

## Brand marks

SVG paths come from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under **CC0 1.0 Universal**. A copy of the license is included at [`assets/logos/LICENSE.md`](../assets/logos/LICENSE.md).

- Simple Icons **16.35.0**: Anthropic, Claude, CrewAI, Cursor, GitHub, GitHub Copilot, Google, Google Gemini, Hugging Face, LangChain, Meta, n8n, Perplexity, Replit, X and Zapier.
- Simple Icons **13.21.0**: OpenAI and Salesforce (not present in the newer package).

Brand marks identify the corresponding products/organizations editorially. They do not imply sponsorship or endorsement. CC0 does **not** grant trademark rights. Organizations without a supplied local brand mark use a text initial rather than a fabricated official logo.
