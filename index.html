USAGE_DESK

Every AI limit you live under — Grok Bot, Muse, Claude Pro — on one desk, with a forecast before you hit the wall.

Private by design: this page makes no network calls and sends nothing anywhere. All data lives in this browser's localStorage. None of these services offers an official usage API, so usage is mostly typed in by hand (Claude has an unofficial shortcut — see Usage snapshots under Data) — and no plan limits are baked in: you set your own.

Sample data is loaded so every module works on first view. The limits, logs, bots and prompts below are examples — replace them with your own.

01Quick log

Read the number off the provider's usage page and type it here. Status: green under 50%, amber 50–89%, red at 90%+. Countdowns refresh on their own.

Usage snapshots

A snapshot is a small JSON file that says "this provider was at X% when I looked". Import one and Usage Desk logs it for you — same as typing the number into Quick log.

Claude: Claude's app has an internal usage endpoint your browser session can already read. Drag this link to your bookmarks bar, open claude.ai, and click it there — it downloads a snapshot file, which you import below. Fine print, plainly: it uses an unofficial endpoint that may break if Anthropic changes it; it runs only on claude.ai; it sends nothing anywhere — the only output is the file it downloads to your machine.
