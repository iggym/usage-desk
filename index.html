Usage snapshots

A snapshot is a small JSON file that says "this provider was at X% when I looked". Import one and Usage Desk logs it for you — same as typing the number into Quick log.

Claude: Claude's app has an internal usage endpoint your browser session can already read. Drag this link to your bookmarks bar, open claude.ai, and click it there — it downloads a snapshot file, which you import below. Fine print, plainly: it uses an unofficial endpoint that may break if Anthropic changes it; it runs only on claude.ai; it sends nothing anywhere — the only output is the file it downloads to your machine.
